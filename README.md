# blazor-dark-theme

https://stackoverflow.com/questions/79243591/how-to-set-dark-theme-in-blazor-project

Bootstrap 5.3 added dark mode, so first update your bootstrap.min.css and bootstrap.min.css.map to 5.3+ (just get the latest)

Make your site dark mode by adding data-bs-theme="dark" to the html tag.

<html lang="en" data-bs-theme="dark">
